A suíte agora distingue e valida com rigor absoluto as três camadas de escala:
1. **Densidade de Pixels (DPR = 2.0 / HiDPI Retina):**
   - Configurado via `deviceScaleFactor: 2.0` no viewport canônico (1277×653);
   - Layout permanece matematicamente invariante (largura: `61.15px`, altura: `61.15px`, ratio: `1.0000`).

   - Renderiza a caixa de layout em 73.5px × 73.5px (área de toque segura, ratio: `1.0000`, círculo perfeito);
   - A evidência é categorizada explicitamente como escala de layout CSS.
3. **Zoom Nativo do Navegador / Escala de Visualização (Page Scale Factor = 1.25 via CDP):**
   - Injetado nativamente pelo Chrome DevTools Protocol (`Emulation.setPageScaleFactor: 1.25`);

### 2.5. Performance e Acessibilidade (`prefers-reduced-motion`)
- **Pacing por Delta-Time:** O loop de animação do `AtlasAIOrb.jsx` agora computa `dt` com base no timestamp real do `requestAnimationFrame`, garantindo fluidez e velocidade idênticas em telas de 30Hz, 60Hz ou 120Hz (ProMotion).
