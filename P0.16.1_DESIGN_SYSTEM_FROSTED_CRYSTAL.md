# AETERNUM ATLAS — DESIGN SYSTEM SPECIFICATION
## P0.16.1 — FROSTED CRYSTAL (CRISTAL FOSCO) AETERNUM 26.1

**Classificação:** Especificação Técnica de Design System  
**Pilar:** Design Visual & Liquid Glass (Aeternum 26.1 Foundation)  
**Status:** Canônico / Homologado  
**Compatibilidade:** Dual-Mode (Dark Liquid Glass & Light Liquid Glass iOS 27)

---

## 1. INTRODUÇÃO & CONCEITO ÓPTICO

O **Aeternum 26.1 Liquid Glass** baseia-se na física óptica de superfícies volumétricas 3D: refração esférica, magnificação, aberração cromática e reflexos especulares.
Historicamente, o sistema contava com quatro materiais canônicos:
1. `clear` (baixa densidade, 48% opacidade, 12px blur) — indicado para overlays e controles transitórios.
2. `regular` (densidade média, 72% opacidade, 20px blur) — indicado para topbars, sidebars e painéis estruturais.
3. `substantial` (alta densidade, 88% opacidade, 28px blur) — indicado para cards centrais e modais com foco.
4. `opaque` (100% opacidade sólida, 0px blur) — indicado para o canvas de fundo e cards de telemetria estática.

A Missão P0.16.1 formaliza o **5º Material Canônico Oficial: `frosted` (Cristal Fosco)**.
O `frosted` foi desenvolvido especificamente para **superfícies flutuantes suspensas no eixo Z** (`A26Popover`, `A26Modal`, menus contextuais e caixas de diálogo). Ele combina alta densidade de refração difusa com atenuação de altas frequências espaciais, garantindo que o texto e os dados de fundo sejam difratados em uma névoa suave e homogênea, sem que palavras ou formas interfiram na legibilidade dos dados flutuantes.

```
                    ESCALA DE MATERIAIS AETERNUM 26.1
┌─────────────┬─────────────────┬───────────────────┬──────────────┬────────────────┐
│    CLEAR    │     REGULAR     │    SUBSTANTIAL    │   FROSTED    │     OPAQUE     │
│   (48% Op)  │     (72% Op)    │      (88% Op)     │   (92% Op)   │    (100% Op)   │
│  12px Blur  │    20px Blur    │     28px Blur     │  24px Blur   │    0px Blur    │
│  Transições │ Barras e Grids  │  Cards Principais │ Popover/Modal│ Canvas/Tabelas │
└─────────────┴─────────────────┴───────────────────┴──────────────┴────────────────┘
```

## 2. TOKENS CANÔNICOS DO MATERIAL FROSTED

Os tokens do material `frosted` estão integrados em `src/styles/A26Foundation.css` e respondem dinamicamente ao tema ativo da plataforma:

### 2.1. Dark Mode (`:root`, `.a26-theme-dark`)
```css
:root {
  /* Fundo escuro enriquecido com tom petróleo ciano profundo */
  --a26-material-frosted-bg: rgb(6 18 23 / 0.92);
  
  /* Desfoque óptico gaussiano balanceado para GPU */
  --a26-material-frosted-blur: 24px;
  
  /* Saturação cromática para evitar aspecto 'cinza lavadão' */
  --a26-material-frosted-saturation: 160%;
  
  /* Borda óptica ciano-translúcida com refração interna */
  --a26-material-frosted-border: rgb(218 251 248 / 0.20);

    inset 0 1px 0 rgb(255 255 255 / 0.16);
}
```

## 3. CLASSE CSS E COMPORTAMENTO ÓPTICO

A classe canônica `.a26-material-frosted` conecta as variáveis ao motor de superfícies:

```css
.a26-material-frosted {
  --a26-material-background: var(--a26-material-frosted-bg);
  --a26-material-blur: var(--a26-material-frosted-blur);
  --a26-material-saturation: var(--a26-material-frosted-saturation, 160%);
  --a26-material-border: var(--a26-material-frosted-border);
  --a26-material-shadow: var(--a26-material-frosted-shadow);
}
```

Quando aplicada em um `<A26Surface material="frosted">`, o elemento herda:
- `background`: gradiente linear sutil de 145deg com brilho ciano em `6% -8%`, somado ao fundo `var(--a26-material-background)`.
- `backdrop-filter`: `blur(var(--a26-material-blur)) saturate(var(--a26-material-saturation))`.
- `box-shadow`: sombreamento volumétrico multietapa.
- `border`: 1px sólido de bisel vítreo refrativo.

## 4. REGRA DE ANINHAMENTO & PREVENÇÃO DE CONFLITOS

### 4.1. O Princípio de Isolamento Flutuante
A regra do Aeternum 26 impede que superfícies estáticas empilhem múltiplos filtros de desfoque (evitando sobrecarga desnecessária na GPU). No entanto, **elementos flutuantes (popovers, tooltips, modais) vivem em uma camada conceitual separada no eixo Z**, mesmo quando estão ancorados no DOM como filhos de um header ou sidebar.

Para expressar esse isolamento no CSS sem quebrar o layout nem depender de portais complexos, foi instituído o atributo canônico:
`data-a26-floating="true"`

A regra de aninhamento em `A26Foundation.css` foi atualizada para:
```css
/* Anulação de blur para elementos comuns aninhados */
[data-a26-blur="true"] [data-a26-blur="true"]:not(.a26-popover):not(.a26-modal):not(.a26-surface--floating):not([data-a26-floating="true"]),
[data-a26-adapter][data-a26-blur="true"] [data-a26-adapter][data-a26-blur="true"]:not(.a26-popover):not(.a26-modal):not(.a26-surface--floating):not([data-a26-floating="true"]) {
  --a26-material-blur: 0px;
  --aog-blur: 0px;
  -webkit-backdrop-filter: none;
  backdrop-filter: none;
}

/* Imunização e ativação garantida para superfícies flutuantes */
.a26-popover,
.a26-modal,
.a26-surface--floating,
[data-a26-floating="true"] {
  -webkit-backdrop-filter:
    blur(var(--a26-material-blur, var(--a26-material-frosted-blur, 24px)))
    saturate(var(--a26-material-saturation, 160%));
  backdrop-filter:
    blur(var(--a26-material-blur, var(--a26-material-frosted-blur, 24px)))
    saturate(var(--a26-material-saturation, 160%));
}
```

## 5. EXEMPLOS DE IMPLEMENTAÇÃO DE COMPONENTES

### 5.1. Implementação no `A26Popover`
Em `src/components/aeternum-26/A26Primitives.jsx`:
```jsx
export function A26Popover({
  open,
  onClose,
  title,
  material = "frosted", // Padronizado para Frosted Crystal
  className = "",
  children,
  ...rest
}) {
  if (!open) return null;
  return (
    <A26Surface
      role="dialog"
      aria-modal="false"
      material={material}
      data-a26-floating="true" // Imunidade contra nested blur stripping
      className={`a26-popover ${className}`}
      {...rest}
    >
      {/* Conteúdo do Popover */}
      {children}
    </A26Surface>
  );
}
```

### 5.2. Implementação no `A26Modal`
```jsx
export function A26Modal({
  open,
  onClose,
  title,
  description,
  actions,
  children,
  ...rest
}) {
  if (!open) return null;
  return (
    <div className="a26-modal-overlay">
      <div className="a26-modal-backdrop" onClick={onClose} />
      <A26Surface
        role="dialog"
        aria-modal="true"
        material="frosted"
        data-a26-floating="true"
        className="a26-modal"
        {...rest}
      >
        {/* Header, Body e Footer */}
      </A26Surface>
    </div>
  );
}
```

## 6. DIRETRIZES DE ACESSIBILIDADE E DEGRADAÇÃO GRACIOSA

1. **Ratios de Contraste WCAG 2.1:**
   - **Títulos e Kicker:** Branco `#f8fafc` sobre fundo `#0e262f` -> Contraste **11.2:1** (Supera amplamente WCAG AAA de 7.0:1).
   - **Textos de Corpo e Resumos:** Ciano claro `#cbd5e1` sobre fundo `#0e262f` -> Contraste **7.8:1** (Supera WCAG AAA de 7.0:1).
   - **Metadados e Timestamps:** Cinza azulado `#94a3b8` sobre fundo `#0e262f` -> Contraste **4.9:1** (Supera WCAG AA de 4.5:1).
   - **Avisos de Manutenção:** Amarelo `#fde68a` sobre fundo ambar translúcido `#78350f` -> Contraste **8.4:1** (WCAG AAA).

2. **Prevenção de Vertigem e Fadiga Visual (`prefers-reduced-transparency`):**
   ```css
   @media (prefers-reduced-transparency: reduce) {
     .a26-material-frosted {
       --a26-material-background: #0b171b;
       --a26-material-blur: 0px;
       --a26-material-saturation: 100%;
       -webkit-backdrop-filter: none;
       backdrop-filter: none;
     }
   }
   ```

3. **Fallback para Ambientes sem Aceleração de Hardware (`@supports not`):**
   ```css
   @supports not ((backdrop-filter: blur(2px)) or (-webkit-backdrop-filter: blur(2px))) {
     .a26-material-frosted {
       --a26-material-background: rgb(6 18 23 / 0.98);
     }
   }
   ```
