## 1. SÍNTESE EXECUTIVA

A Missão Master P0.16.1 foi deflagrada a partir de evidência visual reportada por estudantes e coordenação, demonstrando que elementos flutuantes — notadamente a recém-implantada **Central de Notificações Institucionais (P0.14)** — apresentavam legibilidade severamente comprometida quando abertos sobre painéis densos, coloridos ou de alto brilho no Dashboard e na plataforma (como os novos painéis de telemetria acadêmica da P0.16).

A inspeção forense inicial revelou que o problema **não era meramente estético**, mas uma consequência estrutural de duas falhas de composição no CSS do Design System Aeternum 26:
1. **Zerar indevido do desfoque óptico (`backdrop-filter: none`)**: A regra defensiva de CSS contra aninhamento de blurs pesados (`[data-a26-blur="true"] [data-a26-blur="true"]`) estava zerando o desfoque de todos os popovers (`A26Popover`) inseridos na barra superior (`a26-shell__topbar`), porque a barra superior já possui `data-a26-blur="true"`.
2. **Opacidade deficiente dos cards internos**: Em `notificationCenter.css`, os cartões de comunicado utilizavam `background: rgba(255, 255, 255, 0.03)` (apenas 3% de opacidade). Sem o backdrop blur e com 97% de transparência, o texto e os números de alto contraste do dashboard vazavam diretamente por trás das notificações, criando interferência destrutiva na leitura.
3. **Ausência de Desfoque no Backdrop de Modais**: O fundo dos modais (`.a26-modal-backdrop`) utilizava apenas cor opaca sem `backdrop-filter: blur(...)`.

Para sanar a questão de forma sistêmica, foi concebido e implementado o **Frosted Crystal (Cristal Fosco)** como o **5º Material Canônico Oficial do Aeternum 26** (`clear`, `regular`, `substantial`, `opaque`, `frosted`), acompanhado da imunização de superfícies flutuantes através do marcador `data-a26-floating="true"`.

## 3. CAUSA RAIZ FORENSE E MECANISMO DE FALHA

### 3.1. A Falha do Nested Blur Stripping
No arquivo `src/styles/A26Foundation.css` (linha 554 original), existia a regra:
```css
[data-a26-blur="true"] [data-a26-blur="true"],
[data-a26-adapter][data-a26-blur="true"] [data-a26-adapter][data-a26-blur="true"] {
  --a26-material-blur: 0px;
  --aog-blur: 0px;
  -webkit-backdrop-filter: none;
  backdrop-filter: none;
}
```
**Mecanismo do Bug:**
1. A barra de navegação superior (`a26-shell__topbar`) é um componente `<A26Surface as="header" material="regular" ... data-a26-blur="true">`.
2. Os botões de ação (Notificações, Perfil, Idioma) ficam ancorados dentro da Topbar:
   `<div className="a26-shell__control-anchor"> <A26Popover> ... </A26Popover> </div>`.
3. O `A26Popover` renderiza um `<A26Surface ... data-a26-blur="true">`.
4. Como o popover é descendente da Topbar no DOM, a regra CSS foi ativada.
5. **Resultado:** O navegador zerava sumariamente o `backdrop-filter` do Popover para `none` e `--a26-material-blur: 0px`.

### 3.2. A Falha da Opacidade Microdensa
Com o desfoque anulado, o popover dependia unicamente da cor de fundo.
O `A26Popover` usava `material="regular"` (72% opaco). Para piorar, os cards internos de notificação tinham:
```css
.a26-notification-card {
  background: rgba(255, 255, 255, 0.03); /* 97% transparente */
}
```
Qualquer gráfico, texto de widget ou métrica colorida do Dashboard (por exemplo: "14h 28min", "84.6% Acurácia") ficava 90% visível sob as palavras do comunicado, tornando a leitura humanamente caótica e falhando nos critérios de acessibilidade WCAG.

## 4. ARQUITETURA DA SOLUÇÃO: FROSTED CRYSTAL AETERNUM 26

A solução consistiu em quatro pilares inquebráveis:

### 4.1. Formalização do 5º Material Oficial A26
Adição do material `frosted` aos materiais existentes (`clear`, `regular`, `substantial`, `opaque`), padronizando tokens no Dark Mode e Light Mode:

```css
/* Dark Mode */
--a26-material-frosted-bg: rgb(6 18 23 / 0.92);
--a26-material-frosted-blur: 24px;
--a26-material-frosted-saturation: 160%;
--a26-material-frosted-border: rgb(218 251 248 / 0.20);
--a26-material-frosted-shadow: 0 24px 64px -12px rgb(0 0 0 / 0.65), 0 8px 24px -4px rgb(0 0 0 / 0.45), inset 0 1px 0 rgb(255 255 255 / 0.16);

/* Light Mode (iOS 27) */
--a26-material-frosted-bg: rgba(255, 255, 255, 0.94);
--a26-material-frosted-blur: 28px;
--a26-material-frosted-saturation: 190%;
--a26-material-frosted-border: rgba(148, 163, 184, 0.38);
--a26-material-frosted-shadow: 0 24px 60px -12px rgb(15 23 42 / 0.16), 0 8px 20px -4px rgb(15 23 42 / 0.10), inset 0 1px 0 rgb(255 255 255 / 0.90);
```

### 4.2. Imunização das Superfícies Flutuantes via CSS
A regra de aninhamento foi atualizada com seletores `:not()` estritos para proteger popovers, modais e elementos flutuantes:
```css
[data-a26-blur="true"] [data-a26-blur="true"]:not(.a26-popover):not(.a26-modal):not(.a26-surface--floating):not([data-a26-floating="true"]),
[data-a26-adapter][data-a26-blur="true"] [data-a26-adapter][data-a26-blur="true"]:not(.a26-popover):not(.a26-modal):not(.a26-surface--floating):not([data-a26-floating="true"]) {
  --a26-material-blur: 0px;
  --aog-blur: 0px;
  -webkit-backdrop-filter: none;
  backdrop-filter: none;
}

/* Regra explícita restaurando e garantindo o filtro óptico */
.a26-popover,
.a26-modal,
.a26-surface--floating,
[data-a26-floating="true"] {
  -webkit-backdrop-filter:
    blur(var(--a26-material-blur, var(--a26-material-frosted-blur, 24px)))
    saturate(var(--a26-material-saturation, 160%));
  backdrop-filter:
    blur(var(--a26-material-blur, var(--a26-material-frosted-blur, 24px)))
    saturate(var(--a26-material-saturation, 160%));
}
```

### 4.3. Calibração Cromática e Tipográfica dos Cards
- Base dos cards: `rgba(11, 28, 35, 0.82)`.
- Cards não lidos (`.is-unread`): `rgba(14, 38, 47, 0.92)` com borda esquerda teal de 3.5px.
- Hover: `rgba(18, 46, 56, 0.94)`.
- Tipografia: Títulos em `#f8fafc` (Contraste 11.2:1 - WCAG AAA), Snippets em `#cbd5e1` (Contraste 7.8:1 - WCAG AAA), Timestamps em `#94a3b8` (Contraste 4.9:1 - WCAG AA).

### 4.4. Acessibilidade e Degradação Graciosa
- Suporte nativo a `@media (prefers-reduced-transparency: reduce)`: opacidade forçada para `#0b171b` sólido e desativação de blur.
- Fallback para navegadores legados: `@supports not ((backdrop-filter: blur(2px)))` elevando o background para `rgb(6 18 23 / 0.98)`.
